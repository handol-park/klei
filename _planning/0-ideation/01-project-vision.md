"Klei" is designed to be the **ultimate personal agentic AI**.
It serves as a **personal knowledge maintainer** and **productivity assistant**.

## Core Philosophy
*   **Gradual Growth**: Start small ("lean") and grow iteratively.
*   **Primary Language**: **LEAN** (The project aims to be written mainly in Lean, utilizing other languages/tools like TypeScript or Python only when necessary).
*   **Initial Domain**: Software development and learning assistant.

## Immediate Goal (MVP)
**Feature**: Simple Conversation Partner.
**Interface**: CLI (Command Line Interface).
**Goal**: A basic end-to-end flow where the user can chat with the system via a terminal.

## Proposed Architecture (Updated)
*   **Core Logic**: **LEAN**. This serves as the application entry point, conversation manager, and API client.
*   **Interface**: CLI (Lean Executable).
*   **External Dependencies**: Ollama (Interfaced via HTTP).
*   *Note: Python agent layer has been removed.*
